## ⏱️ ShiftStack

**Full Stack Employee Time Tracking Platform**

ShiftStack is a production-style SaaS portfolio project designed to manage employee time tracking across mobile and web applications.

### Architecture

```text
React Native Mobile App
        │
        ▼
Node.js / Express REST API
        │
        ├──── RabbitMQ ──── Background Workers
        │
        ▼
PostgreSQL / Supabase
        │
        ▼
Next.js Management Dashboard
```

### Features

* Secure employee authentication
* JWT-based authorization
* Clock In / Clock Out
* React Native mobile application
* Next.js management dashboard
* Employee, Manager, and Admin roles
* Role-Based Access Control
* RabbitMQ message processing
* Audit logging
* Weekly employee reports
* CSV report export
* PostgreSQL database
* REST API
* Rate limiting and security middleware
* Docker support
* Production deployment architecture

## 🎬 IT490 Distributed Movie Platform

**Distributed Multi-Server Web Application**

An enterprise-style distributed application built across multiple Linux virtual machines using RabbitMQ for application communication.

The project separates the web application, database, API services, and message broker into independent systems.

### Architecture

```text
Web Application
      │
      ▼
   RabbitMQ
   /      \
  ▼        ▼
Database   API Workers
Worker
  │
  ▼
MySQL
```

### Features

* Distributed multi-VM architecture
* RabbitMQ message queues
* Secure authentication
* Server-side session management
* Movie search and API integration
* Favorites
* Watchlists
* Friend requests
* Friend favorites
* Background API workers
* MySQL database
* Linux server administration
* Firewall configuration
* Private networking
* Centralized logging
* Service monitoring
* Worker failover concepts
* Development, QA, and production environments
